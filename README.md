# 여행설계사 · 부산

손님의 예산·일정·체력·취향에 맞춰 부산 여행 일정을 짜주는 브라우저 게임.

## 실행

`index.html` 을 브라우저로 열면 된다. 빌드·설치·서버 전부 필요 없다.

`index.html?test` 로 열면 개발자 콘솔에서 엔진 자체 점검이 돌아간다.

## 구조

```
index.html          UI + 게임 엔진 (전부 인라인)
data/busan.js       부산 지역 데이터 — 장소·의뢰·교통편
assets/             지도
```

지역 추가는 `data/xxx.js` 를 만들어 `REGIONS.xxx` 로 등록하고 `index.html` 에
`<script>` 한 줄을 더하면 된다. 엔진은 지역 수에 관계없이 그대로다.

## 규칙 요약

- **이동시간**: 실좌표 직선거리 × 1.35 ÷ 수단별 속도. 출퇴근(07:30~09:30, 18:00~20:00)에는
  버스·택시·렌터카가 최대 1.5배, 지하철은 영향 없음. 주말은 정체 없음.
- **체력**: 이동·관광은 깎이고 식사는 회복. 수면이 부족하면 다음날 한계가 준다.
  의뢰인 타입(아침형·야행성·에너자이저·심한 멀미)마다 소모 방식이 다르다.
- **요일**: 시설별 정기 휴무, 금·토 숙박비 40% 할증.
- **취향**: 연령대별로 선호하는 관광지 타입(액티비티·쇼핑·자연경관·포토스팟·문화)이 있어
  만족도가 달라진다.

이동시간·요금·좌표는 실제 데이터를 바탕으로 한 근사값이다. 정확한 도로 시간이 필요하면
`travel()` 함수 하나만 실 경로 API로 교체하면 된다.
