쓰는 법 — ① 위 사진 폴더 지정 으로 assets/photos 를 고른다 ② 왼쪽에서 장소를 고른다 ③ 사진을 끌어다 놓는다 ④ 드래그로 위치를, 휠·슬라이더로 크기를 맞춘다 ⑤ 저장 하면 <id>.jpg 로 폴더에 바로 쓴다.
폴더 지정이 안 되면 — 브라우저가 file:// 에서 폴더 쓰기를 막는다. 저장소 폴더에서 npx serve 나 python -m http.server 를 띄우고 localhost 주소로 이 페이지를 열면 된다. 그래도 안 되면 저장 버튼이 내려받기 로 바뀌니, 받은 파일을 assets/photos 로 옮기면 똑같다.
